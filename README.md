# ComicStore
Repo for group project about digitizing a comic book store's inventory management and ordering process

Releases: https://github.com/DRSchoolProj/ComicStore/releases/tag/v1.0.0

To Install:

1. Download ComicStore-Release.zip
2. install Python 3.10 or newer (on Windows, tick "Add to PATH")
3. unzip the folder
4. Open a terminal from within the folder
5. run "python main_menu_gui.py"
